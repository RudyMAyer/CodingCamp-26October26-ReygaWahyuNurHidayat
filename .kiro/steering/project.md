# Expense & Budget Visualizer

Mini project for RevoU CodingCamp 26 October 2026.

## Stack
- HTML, CSS, Vanilla JavaScript (no frameworks)
- Chart.js for data visualization
- localStorage for client-side data persistence

## Features
- Add income/expense transactions with category
- Scrollable transaction list with delete
- Total balance display (auto-updates)
- Doughnut chart by category (Chart.js)
- Dark/light mode toggle
- Custom categories (user-defined, persisted)
- Spending limit highlight (warning at 80%, over-limit at 100%)

## File Structure
- `index.html` — main page
- `css/style.css` — all styles
- `js/script.js` — all logic
